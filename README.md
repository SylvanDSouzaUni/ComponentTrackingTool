Version 3.0:

This is the first working prototype for the Component Tracking Tool.
It meets all requirements, has passed formal testing, and is ready for end use.

Noteable additions:
1) Full front-end support.
2) Role-based access control to sensitive functions

Use Guide for Users:
1) Open the code and run main.py using an appropriate IDE.
2) Open the console.
3) All front-end interaction occurs through the console. Apon running main.py, you should be greeted with a login prompt. The database is initialised with a starting admin who can build the database as they see fit.
   The login credentials for this starting admin is as follows:
   Username: admin
   Password: admin123
4) Apon logging in, you will see a main menu screen.
5) Follow the on screen prompts to complete your desired actions. You can navigate to desired actions by inputting the number corresponding to the action. Error messages and Console prompts are useful and intuitive, meaning use should be simple when following these prompts.
